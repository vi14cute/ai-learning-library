## Suggested learning order

1. GPU concepts: learn the vocabulary.
2. NVIDIA Build guide: try one small hosted model task.
3. Graphify: map a small codebase.
4. Agent-Reach: explore an agent research task.
5. Cloudflare Code Mode article, then API reference: implement a small tool workflow.
6. FreeLLMAPI: compare provider behavior in personal experiments.
7. REA: advanced application analysis on authorized targets.
8. Explore creative apps, film creation or startup skills based on your interests.

This order is an editorial suggestion. Define one small outcome, supply relevant context, ask for evidence, test the result and record what worked.

## Keeping the library useful

- Use **Sync fork → Update branch** to bring in upstream changes. Review your own edits first. Fork updates are not automatic.
- Preserve project licenses, notices and author credits. Code, demo media, fonts and branding can have different terms.
- Use original repositories for current installation instructions, releases and dependencies. Forks do not duplicate upstream issues, pull requests, release binaries, packages, secrets or all settings.
- Keep API keys outside Git history. Tracking parameters and access tokens were removed from published links.
- This index stores links and concise notes, not full copies of third-party articles.
